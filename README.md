# 八牌 v0.8.5 — ボイスチャット試験版

- Renderのゲーム管理は維持し、音声だけWebRTC P2Pで接続します。
- 対戦部屋に2人が入った後、各自が「マイクON・通話開始」を押しマイクを許可してください。
- 音が出ない場合は「音声再生」を押してください。音量はゲーム効果音と別に調整可能です。
- GitHubで `multiplayer.html`、`server.js`、`index.html`、`sw.js` を更新し、Vercel / Renderの両方が最新になってから対戦してください。
- STUNのみの試験版です。通信環境によっては直接接続できず音声が使えません。遠隔対戦の安定化にはTURNサーバーが必要です。
- マイクの音声はゲームサーバーに保存されませんが、接続用のSDP/ICE情報をRenderが中継します。
- ブラウザを閉じると通話終了。画面OFFでの継続は保証されません。
